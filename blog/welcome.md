# Welcome to My Blog

This is a sample blog post to demonstrate the blog functionality of my GitHub Pages website. The blog system automatically reads markdown files from the `blog/` directory and displays them in a clean, organized format.

## Features

- **Automatic Discovery**: All `.md` files in the blog directory are automatically detected
- **Markdown Support**: Full markdown rendering with syntax highlighting
- **Responsive Design**: Works great on desktop and mobile devices
- **GitHub Integration**: Pulls content directly from your repository

## Getting Started

To add new blog posts, simply create new markdown files in the `blog/` directory. The system will automatically:

1. Extract the title from the first heading or filename
2. Generate an excerpt from the first paragraph
3. Display the post in the blog list
4. Allow readers to click through to read the full post

## Code Example

Here's a simple JavaScript example:

```javascript
function greetUser(name) {
    return `Hello, ${name}! Welcome to my blog.`;
}

console.log(greetUser("World"));
```
