This site doesn't have accounts, forms, or a newsletter. There isn't much to collect, and I've kept it that way on purpose.

## Analytics

This site uses [Plausible Analytics](https://plausible.io), a privacy-friendly analytics tool. Plausible doesn't use cookies, doesn't collect personal data, and doesn't track you across other sites. It reports aggregate stats like page views, referrers, and general location (country/region, derived from IP address, which is never stored).

If you'd rather not be counted at all, you can [opt out of analytics]({{ '/plausible-exclude/' | relative_url }}) for your browser.

## Comments

Blog post comments are powered by [giscus](https://giscus.app), which stores comments as [GitHub Discussions](https://docs.github.com/en/discussions) on this site's repository. Reading comments doesn't require anything of you, but posting one requires signing in with a GitHub account and authorizing the giscus app, which is handled entirely by GitHub.

## Fonts

Pages load fonts from Google Fonts. Loading a font from Google's servers means your browser makes a request to Google, which can see your IP address. See [Google's privacy policy](https://policies.google.com/privacy) for how that request is handled.

## Hosting and delivery

This site is built as static files and hosted on GitHub Pages, delivered through Cloudflare's CDN. Both may log standard access data (like IP addresses) as part of serving and caching the site. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) and [Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/) for details.

## Cookies

This site doesn't set any cookies of its own. GitHub and Cloudflare may set their own as part of the services described above.
